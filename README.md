Just a simple hangover calculator app. 
Made with a dose of humour. 

You get some tips depending on how much youve had last night.

To run it:
  python3 -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt
  flask --app app run

Some cosmetic stuff Claude helped out with, like CSS and some JScript stuff.
